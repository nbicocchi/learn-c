# Learn C

Materiale didattico, esempi ed esercizi per lo studio del linguaggio C.

## Software

* [CLion](https://www.jetbrains.com/clion/)
* Un compilatore C: [GCC](https://gcc.gnu.org/) o [Clang](https://clang.llvm.org/)
* [CMake](https://cmake.org/) e uno strumento di build compatibile, ad esempio Make o Ninja

## Libri

* **Facchinetti, Larizza, Rubini — Programmare in C**
* Loosemore e altri — The GNU C Library Reference Manual

## Documentazione e tutorial

* [Python Tutor — Visualizzazione dell'esecuzione](https://pythontutor.com/)
* [C reference — Linguaggio e libreria standard](https://en.cppreference.com/w/c)
* [GNU C Library — Manuale di riferimento](https://www.gnu.org/software/libc/manual/)
* [Wikibooks — C Programming](https://en.wikibooks.org/wiki/C_Programming)
